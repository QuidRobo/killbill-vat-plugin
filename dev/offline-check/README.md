# Offline check

`./run.sh` compiles every plugin and formatter source file against hand-written Kill Bill API
stubs and then runs **the repository's real test classes**, the same ones `mvn test` runs, with
no Maven and no network.

It works by shadowing two things:

- `stubs/`, generated by `gen-stubs.py`: the Kill Bill and Jackson types the plugin compiles
  against.
- `testng/`: just enough of `org.testng.annotations.Test` and `org.testng.Assert` for the test
  sources to compile, plus `TinyTestRunner`, which calls every no-argument `@Test` method by
  reflection and reports what threw.

Because the tests themselves live under `src/test/java`, there is no second copy of the
assertions to drift out of date. Add a test class named `Test*` and both runners pick it up.

**These stubs are not the real API.** They exist so the plugin can be type-checked and its
arithmetic exercised in environments that cannot reach Maven Central. Signatures mirror
killbill-api 0.54.0, killbill-plugin-api 0.27.3, killbill-base-plugin 5.1.9 and
killbill-platform 0.41.18, but method bodies return null and nothing is behaviourally faithful.

`TinyTestRunner` supports no groups, no ordering, no data providers and no expected exceptions.
None are used here. If a test ever needs one, delete this runner rather than grow it.

Always run `mvn clean install` before releasing.

If a stub disagrees with the real API, the real API is right: fix the stub.
